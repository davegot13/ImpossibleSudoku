# Impossible Sudoku Support

Email davegot+impossiblesudoku@gmail.com with questions, bug reports, or feature requests. Include your device model and iOS version if you are reporting a bug.

## Common questions

**Why did my run end?** A run ends when you lose all three hearts. Each wrong digit costs one heart. Solving a puzzle with no mistakes gives one heart back.

**Can my score go below zero?** Yes. Mistakes, hints, and reveals subtract points even when your score is low, so a run can carry a debt that later puzzles pay back. A run only counts as a personal best when it ends above zero.

**Where are my scores stored?** On your device only. Deleting the app deletes them.

**Is there an easy mode?** No. Every puzzle is rated 4.0 or harder.
